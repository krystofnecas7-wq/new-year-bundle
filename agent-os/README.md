# agent-os (znalost pro lokální Kiro)

Tahle složka obsahuje projektové soubory NYB doplněné o znalost z webového Kiro chatu (appka, web, vizuál, značky, budoucí plán). Cílem je dostat tuhle znalost do tvého lokálního Agent OS na PC, aby ji Kiro na počítači znalo taky.

## Co je uvnitř

* `AGENTS.md` rozcestník (jen odkaz, stejně jako tvůj lokální).
* `project_info.md` jediná pravda o projektu. Vychází z tvého lokálního souboru, doplněné o věci z webového chatu, označené „(web chat)“, plus nový bod 12 (appka vs. dokument).
* `app_web.md` NOVÝ soubor. Celý popis online appky/webu (PWA): co umí, jak je postavená, kde běží, styl, logo, co zbývá.

## Jak to dostat do lokálního Agent OS

Tyhle soubory jsou verze z webového Kiro workspace. Do svého PC je dostaneš jedním ze způsobů:

1. **Přes GitHub (doporučeno):** jsou v repu `krystofnecas7-wq/new-year-bundle` ve složce `agent-os/`. Stáhni si je a zkopíruj do složky projektu NYB ve svém Agent OS (`...\Muj-Agent-OS\...\NYB\`).
2. **Ručně:** otevři si obsah souborů a vlož do svých lokálních.

Pak:

* `project_info.md` ve svém Agent OS nahraď touhle verzí (nebo do své verze přenes bloky „(web chat)“ a bod 12).
* `app_web.md` přidej jako nový soubor vedle `project_info.md`.
* V lokálním `AGENTS.md` přidej do seznamu ke čtení odkaz na `app_web.md` (bod 3), jak je to tady.

## Důležité

* Sladění appky a dokumentu (počet a struktura zón, Fidži, Grónsko, výzvy) je otevřený úkol. Zdroj pravdy je `project_info.md`. Viz tam bod 12.
* Tenhle workspace (webové Kiro) a tvůj lokální Agent OS jsou dvě oddělená prostředí. Nic se mezi nimi nesynchronizuje samo, přenos je ruční přes GitHub.
